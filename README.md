# 黑白像素拓扑分析（pixels）

原生 TypeScript 单页应用：在 4～64 边长的二值方格上作画，实时给出数字拓扑统计，并支持“单格翻转消孔”扫描。画布显示与统计共用同一套邻接定义，保证拓扑结论一致。

## 邻接约定（核心规则）

| 对象 | 邻接 | 说明 |
| --- | --- | --- |
| 黑格 | 八邻接 | 对角相接算同一块 |
| 白格 | 四邻接 | 对角相接**不**算连通 |
| 外部 | — | 触及画布边界的白域 |
| 孔洞 | — | 不触及边界的白域 |
| 欧拉数 | — | `欧拉数 = 黑域数 − 孔洞数` |

黑域周长按“四边暴露周长”计：每个黑格朝向白格或画布外的边数之和。

## 功能

- 边长 4～64 的方格画布，黑/白笔刷（左键当前笔刷，右键擦白），清空；
- 实时统计：黑域数、孔洞数、欧拉数、黑格总数，每个黑域的面积与周长，每个孔洞的面积；
- 可切换蒙层：黑域 / 孔洞 / 外部白域，逐格精确着色并标注连通域编号（格子足够大时）；
- 导入 / 导出：JSON `{"size": n, "rows": ["0101", ...]}`，也接受行数组 JSON 或纯文本 0/1 行；
- 单格翻转扫描：列出所有“恰好消去一个孔且黑域数不变”的位置（按行列排序）；选中候选后在画布上预览翻转结果与各项差异，**确认后才改写原图**，改写后自动重扫。

## 本地开发

```bash
npm install
npm run dev      # 开发服务器
npm test         # Vitest：独立泛洪对拍 + 小网格穷举
npm run build    # 类型检查 + 打包到 dist/
```

## Docker（离线运行）

```bash
docker compose up --build pixels
# 打开 http://localhost:8080
```

镜像为多阶段构建：构建阶段安装依赖、运行 Vitest 对拍测试并打包；运行阶段仅是 nginx 托管的静态文件，无需外网。

## 测试策略（tests/topology.test.ts）

- **独立实现对拍**：测试文件内用队列式 BFS 重新实现整套统计，与源码（迭代泛洪）互相校验；
- **穷举**：2/3/4 阶全部二值图（共 65536+ 张）逐张比对黑域数、孔洞数、欧拉数、各黑域面积与周长；3 阶全枚举比对翻转候选；5～16 阶随机网格双项比对；
- **专项**：对角接触（2×2 对角、3×3 对角链、4×4 菱形环围孔）、边缘缺口（环在画布边开缺口后孔变外部）、一格封口（单格孔的填充候选、两格孔无法单格填净）。
